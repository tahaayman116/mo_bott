# البوت المركزي 🎛️

بوت تحكم واحد بأزرار، يشغّل أرقام تليجرام كتير — **سيشن واحدة نشطة في المرة** (خفيف على Termux).

## الأزرار

| الزر | بيعمل إيه |
|---|---|
| ➕ انضم لجروبات | ابعت لينكات → قايمة → **تلقائي بوقت** (تختار الدقايق، بدون حد يومي) أو **يدوي** (زر لكل لينك) |
| 📋 تجميع | ابعت أي رقم متسجل → يجيب **الجروبات + القنوات** اللي داخلها (العامة برابط، الخاصة بأسمائها) |
| 📢 نشر إعلان | ابعت النص → اختار كل كام دقيقة → **علّم الشاتات اللي عايزها (جروبات + قنواتك، أو الكل)** → ينشر واحد ورا التاني لحد ما يخلص + زر إيقاف |
| 📱 الأرقام | قايمة الأرقام → دوس للتبديل (يفصل الحالي ويوصل المختار) → إضافة رقم (كود مرة واحدة) → حذف |
| 📊 حالة | الأرقام + النشط + العدادات اليومية |
| ⏹ إيقاف الكل | يوقف الانضمام والنشر فورًا |

## المهم

* مفتاح `API_ID`/`API_HASH` **واحد** لكل الأرقام (مفتاح التطبيق مش الرقم).
* البوت المركزي لا يرد إلا على `OWNER_ID` (رقمك أنت) — أي حد تاني يتجاهل في صمت.
* كل رقم له ملف سيشن لوحده في `sessions/` — تسجيل الدخول مرة واحدة بالكود (+ باسورد التحقق بخطوتين لو فيه).
* حدود يومية افتراضية: 100 منشور (الانضمام بدون حد) — وتوقف تلقائي عند تحذير Flood من تليجرام.

## التشغيل (Termux)

```
pkg install python -y
pip install -r requirements.txt
cp .env.example .env
nano .env   # API_ID + API_HASH + CONTROL_BOT_TOKEN + OWNER_ID
python main.py
```

* `CONTROL_BOT_TOKEN`: من @BotFather (New Bot).
* `OWNER_ID`: من @userinfobot (رقمك العددي).
* افتح بوت التحكم وابعت `/start`.

## ⚠️ بصراحة

الانضمام والنشر الجماعي (خصوصًا من كذا رقم) أعلى خطر حظر على الحسابات. ابدأ برقم أو اتنين وحدود صغيرة وراقب.
